# Security Policy

## Supported Versions

The following versions of the application are actively supported with security updates and patches:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this ERP & POS platform seriously. If you identify a security vulnerability or potential exploit, please report it responsibly:

1. **Do not disclose the vulnerability publicly** through GitHub Issues, Discussions, or social media.
2. Email full vulnerability details directly to:
   - **buyeez2024@gmail.com**
3. Please include the following information in your report:
   - Type of vulnerability (e.g., authentication bypass, injection, authorization flaw, rate limiting).
   - Detailed step-by-step instructions to reproduce the issue.
   - Affected endpoints or components.
   - Proof of concept (PoC) scripts or screenshots, if available.
   - Any suggested mitigations or patches.

## Security Response Timeline

* **Initial Response:** We will acknowledge receipt of your vulnerability report within **24–48 hours**.
* **Investigation & Assessment:** We will validate the issue and determine severity within **3–5 business days**.
* **Fix & Release:** A patch or security hotfix will be prioritized based on severity and released as soon as verified.
* **Public Disclosure:** Public disclosure will occur only after a fix has been committed and deployed to protected environments.

## Scope & Guidelines

- Do not perform destructive attacks or attempt data corruption on production environments.
- Do not attempt denial of service (DoS/DDoS) attacks.
- Do not access, modify, or leak private user data belonging to other businesses or accounts.
